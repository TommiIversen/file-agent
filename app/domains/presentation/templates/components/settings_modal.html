Output Folders

Enabled: Files are organized into subfolders based on rules.
Disabled: All files go directly to the destination folder.

Example 1 — Categorized by type + date

Rules (one per line):
pattern:*Cam*;folder:KAMERA/{date}
pattern:*PGM*;folder:PROGRAM_CLEAN/{date}
pattern:*CLN*;folder:PROGRAM_CLEAN/{date}
pattern:*;folder:OTHER/{date}
Result:
251022_1400_Cam1.mxf → {{"\\\\NAS\\"}}KAMERA{{"\\251022\\"}}251022_1400_Cam1.mxf
251022_1500_PGM.mxf  → {{"\\\\NAS\\"}}PROGRAM_CLEAN{{"\\251022\\"}}251022_1500_PGM.mxf
251022_1600_CLN.mxf  → {{"\\\\NAS\\"}}PROGRAM_CLEAN{{"\\251022\\"}}251022_1600_CLN.mxf
251022_1700_Other.mxf → {{"\\\\NAS\\"}}OTHER{{"\\251022\\"}}251022_1700_Other.mxf

Example 2 — Only date folders

Rules: pattern:*;folder:{date}
Result:
251022_1400_Cam1.mxf → {{"\\\\NAS\\251022\\"}}251022_1400_Cam1.mxf
251022_1500_PGM.mxf  → {{"\\\\NAS\\251022\\"}}251022_1500_PGM.mxf

Example 3 — Group by date + time

Rules (one per line):
pattern:*KAM*;folder:KAMERA/{date}/{time}
pattern:*PGM*;folder:PROGRAM/{date}/{time}
pattern:*;folder:OTHER/{date}/{time}
Result:
260408_154246_KAM_3.mxf → {{"\\\\NAS\\"}}KAMERA{{"\\2604" + "08\\"}}154246{{"\\" }}260408_154246_KAM_3.mxf
260408_154246_KAM_5.mxf → {{"\\\\NAS\\"}}KAMERA{{"\\2604" + "08\\"}}154246{{"\\" }}260408_154246_KAM_5.mxf
260408_162000_PGM.mxf  → {{"\\\\NAS\\"}}PROGRAM{{"\\2604" + "08\\"}}162000{{"\\" }}260408_162000_PGM.mxf
260408_170000_Misc.mxf → {{"\\\\NAS\\"}}OTHER{{"\\2604" + "08\\"}}170000{{"\\" }}260408_170000_Misc.mxf

Variables

{date}Date extracted from filename {time}Time extracted from filename {filename}Full filename with extension {name_no_ext}Filename without extension

Date Format: filename[0:6] extracts the first 6 characters as date (YYMMDD).

Time Format: filename[7:13] extracts characters 7–13 as time (HHMMSS).

Default Category: Folder used for files that don't match any rule. Tip: add pattern:*;folder:OTHER/{date}/{time} as the last rule for full control over the fallback template.
